An entry for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty ($2 in USDC). The program writes one line — the excuse a dog gives after being caught eating the homework, in the dog's own voice — to `/output/entry.txt`.

> The homework was on my bed — I mean, your bed, the one I sleep on — so I graded it. It failed. I ate the evidence.

One concrete scene (the bed), one reversal (the dog graded the homework), one landing line (it failed, so the evidence is gone). A dog who believes it has done nothing wrong.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, 114 characters) and verifies it by reading it back.
